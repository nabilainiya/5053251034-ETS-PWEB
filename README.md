# myRupiah

**myRupiah** adalah aplikasi web pencatatan keuangan pribadi sederhana yang dirancang untuk pengemudi ojek online (ojol). Aplikasi ini membantu pengguna mencatat pendapatan dan pengeluaran harian serta memantau aktivitas keuangan dalam satu tempat.

## Fitur

- **Pencatatan Pendapatan** — Mencatat pendapatan dari layanan ojek online maupun sumber lainnya.
- **Pencatatan Pengeluaran** — Mencatat pengeluaran harian, seperti bensin, makanan dan minuman, perawatan kendaraan, serta parkir.
- **Total Pendapatan Ojol Hari Ini** — Menampilkan total pendapatan yang diperoleh dari pekerjaan ojek online pada hari ini.
- **Ringkasan Keuangan** — Menampilkan ringkasan pendapatan, pengeluaran, dan saldo berdasarkan transaksi yang tercatat.
- **Riwayat Transaksi** — Melihat kembali transaksi keuangan yang telah dicatat.
- **Penyimpanan Data** — Menyimpan data transaksi menggunakan Local Storage pada browser.

## Target Pengguna

Target utama aplikasi ini adalah pengemudi ojek online yang membutuhkan cara sederhana untuk mencatat pendapatan dan pengeluaran harian tanpa harus menggunakan aplikasi pengelolaan keuangan yang rumit.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Cara Menjalankan Aplikasi

1. Clone atau unduh repositori ini.
2. Buka folder proyek.
3. Buka file `index.html` menggunakan browser.
4. Mulai catat pendapatan dan pengeluaran.

Aplikasi dapat dijalankan langsung melalui browser tanpa instalasi tambahan.

## Penyimpanan Data

Aplikasi menggunakan **Local Storage** pada browser untuk menyimpan data transaksi. Data dapat tetap tersedia ketika aplikasi dibuka kembali melalui browser yang sama, kecuali jika data penyimpanan dihapus atau lingkungan browser berubah.

## Tujuan Proyek

Proyek ini dikembangkan untuk menyediakan alat pencatatan keuangan yang sederhana dan sesuai dengan kebutuhan harian pengemudi ojek online. Aplikasi ini diharapkan dapat mempermudah pencatatan pendapatan dan pengeluaran serta membantu pengguna memahami kondisi keuangan hariannya.
